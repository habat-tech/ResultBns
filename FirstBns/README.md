# نظام ترتيب الطلاب

نظام لعرض وترتيب الطلاب بناءً على معدل GPA مع معالجة القيم المكررة.

## المميزات
- ترتيب الطلاب تنازلياً حسب GPA
- معالجة القيم المكررة
- عرض في جدول مع تنسيق RTL
- تمييز القيم المكررة بلون مختلف

## كيفية الاستخدام
1. قم بتحميل المشروع
2. أضف ملف JSON يحتوي على بيانات الطلاب
3. افتح index.html في المتصفح

## البيانات المطلوبة
يجب أن يكون ملف JSON بالتنسيق التالي:
```json
[
  {
    "اسم الطالب": "اسم الطالب",
    "رقم الجلوس": "رقم الجلوس",
    "GPA": 3.71
  }
]
